TRANSPARENT BOUNDARIES // WHAT AEGIS DOES NOT PROTECT AGAINST

Documented Architectural Non-Goals

  • Chatbot Conversational Hallucinations: If an agent without tools outputs incorrect factual statements to a human user without executing a contract action, Aegis does not validate factual truth.
  • Compromised Underlying OS Kernel / Rootkit: If the physical hardware hosting the Python process is compromised at the kernel level, hardware security modules (HSM) must be used.
  • Pre-Training Corpus Poisoning: Aegis safeguards runtime actuation. Model weights poisoned at pre-training time remain contained from unauthorized actuation, but the model's latent weights are not scrubbed.
