AEGIS-BFSI: Making a compromised banking agent provably harmless

The Core Philosophy

AEGIS-BFSI is an enforcement layer that makes a compromised banking agent harmless. Every inbound payload is screened by a fail-closed semantic gateway (8 detectors + a Gemini 2.5 Flash judge), and every action an agent proposes must satisfy a signed capability contract before a single-use, HMAC-verified execution token is minted.

BFSI Domain Verticalization

Dedicated banking pack shipping out-of-the-box: SWIFT manipulation detection, four-eyes wire-transfer gating, IBAN egress scanning, and DORA / MiFID II / EU AI Act control mappings.

Gateway Decision

VERDICT: BLOCK / SANITIZE

If injection score > threshold, drops payload immediately, logs event to hash-chain, and writes durable evidence to Firestore.

Contract Monitor Decision

VERDICT: DENY / DEFER

Prohibited tools (e.g. execute_swift_message) are denied. Sensitive tools (e.g. wires > $10k) are deferred to human dual-signatory.

Execution Decision

VERDICT: MINT & BURN TOKEN

Only verified actions receive a single-use HMAC token. Executor validates token signature and burns it instantly upon execution.
